# Kairos

Employee time tracking application. Workshop project for spec-driven development.

## Where things are
- Requirements: prd.md (the source of truth for what to build)
- Extra context: context/ (design theme, engineering standards)
- Approved designs: docs/designs/
- Build plan: implementation-plan.md

EGM artifact directory: .egm

## Rules
- Do not write application code until docs/designs/ contains an approved design.
- Implement one sub-task from implementation-plan.md at a time. Touch only the files it lists.
- When a requirement is unclear, ask. Do not guess.
- Refer to requirements by their PRD IDs (for example TIME-3).
