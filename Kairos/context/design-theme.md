# Design theme: Kairos

## Feel
A dense, calm work tool. No marketing visuals, no illustrations.

## Layout
- Dark top bar with app name, search and user menu.
- Weekly view: seven equal columns, Monday to Sunday. Day total at the top of each column.
- Entries are solid colour cards stacked under an "add" button.
- On screens narrower than 768 px the days stack vertically.

## Colour
| Use | Value |
| --- | --- |
| Top bar | #111111 |
| Primary action | #1F2A44 |
| Work entry | #00A67E |
| Leave entry | #B45309 |
| Designated holiday | #5B21B6 |
| Warning (incomplete day) | #B91C1C |
| Background / text | #FFFFFF / #1A1A1A |

Never use colour as the only signal. Pair it with a label or icon.

## Typography
- UI text: Inter, 14 px base.
- Numbers (hours, totals): a condensed face, large and bold.

## Components
- Component library: (your choice, for example MUI or shadcn/ui)
- Forms open in a centred modal. Save is the only primary button.

## Tone of messages
Short and specific. Say what went wrong and what to do next.
